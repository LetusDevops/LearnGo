# GoLang 10-Day Path for DevOps - Day 1: Introduction to GoLang

Welcome to Day 1 of the **GoLang 10-Day Path for DevOps**! In this section, we will cover the basics of GoLang, including its syntax, variables, and data types.

## Objectives
- Understand the basic syntax of GoLang.
- Learn about variables and data types in Go.
- Get familiar with Go's unique features.

## Resources
- [Go Tour](https://tour.golang.org/)
- [GoLang Documentation](https://golang.org/doc/)
- [Effective Go](https://golang.org/doc/effective_go.html)

## Getting Started
1. Install GoLang on your system if you haven't already. Follow the instructions [here](https://golang.org/doc/install).
2. Set up your Go workspace.
3. Write your first Go program:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, GoLang!")
}
```

## Exercises
- Write a Go program to print "Hello, World!".
- Create a program that declares and initializes variables of different data types.
- Experiment with Go's `fmt` package to format and print output.

Happy coding!
